# 公開手順と公開後の確認（GitHub Pages）

## 0. 公開前に確認済みのことと、未確認のこと

### 公開前に確認済みのこと

- 公開対象のファイルに、API キー・トークン・パスワード・個人情報が含まれていないこと
- テスト出力（`tests/output/`）が登録対象から除外されていること（`.gitignore` で除外）
- 単体テストと E2E テストがすべて成功すること（[README.md](../README.md)「5. テスト」）
- GitHub Pages と同じ `/リポジトリ名/` 配下からの配信を開発環境で再現し、読み込みエラーがないこと

### まだ確認していないこと

- iPhone Safari の実機での表示・操作
  - 開発環境の Chromium で iPhone 13 相当の画面サイズとタッチ操作を再現して確認しただけです。Safari のエンジン（WebKit）では確認していません。
- GitHub Pages に公開した状態での動作
  - 公開後に、下の「2. 公開後の確認チェックリスト」で確認してください。
- Android 実機、Firefox、Safari（Mac）での動作
- 出力した CSV を実際の Microsoft Excel で開いたときの表示

## 1. スマートフォンからの設定手順（画面ごと）

- iPhone の Safari で github.com にログインして操作する前提で書いています。
- GitHub の画面は予告なく変わることがあり、ボタンの位置や名前が異なる場合があります。
- スマートフォン表示で項目が見つからない場合は、Safari のアドレスバー左の「ぁあ」から「デスクトップ用Webサイトを表示」を選ぶと、PC と同じ画面になります。
- GitHub Mobile アプリでは、リポジトリの公開範囲や Pages の設定ができない場合があります。Safari で操作してください。

### 画面1：`main` ブランチにファイルが入っていることを確認する

GitHub Pages は、選んだブランチ（ここでは `main`）の内容を公開します。

1. Safari でリポジトリのトップページを開きます。
2. ブランチ名が `main` になっていることを確認します。
3. `index.html`、`app.js`、`calc.js`、`styles.css` がファイル一覧に表示されていることを確認します。
4. 画面上部の **Actions** タブで、自動テスト（test）が緑のチェックになっていることを確認します。

### 画面2：リポジトリの公開範囲を確認する

GitHub Free プランでは、Private リポジトリで GitHub Pages を使えません。リポジトリが Private の場合は、どちらかを選んでください。

| 選択肢 | 内容 |
|---|---|
| A | リポジトリを Public（公開）に変更する。無料で使える |
| B | 有料プラン（GitHub Pro など）を使い、Private のまま Pages を使う（サイト自体はインターネットに公開されます） |

**選択肢 A の場合**

1. リポジトリのトップで **Settings** タブを開きます（タブが横に隠れている場合は、タブを横にスクロールするか「…」から開きます）。
2. **General** の画面を一番下までスクロールし、**Danger Zone** の **Change visibility** を押します。
3. **Change to public** を選び、表示される確認に従ってリポジトリ名を入力して確定します。

> **Public にする前に確認してください**
>
> Public にすると、次のものがすべて誰でも閲覧できるようになります。
>
> - ソースコード（テスト、SKILL.md、docs を含む）
> - コミット履歴（作成者名・メールアドレス・日時・コミットの本文）
> - Actions の実行記録
>
> コミットにメールアドレスを残さないため、GitHub の Settings → Emails で「Keep my email addresses private」を有効にし、コミットには `…@users.noreply.github.com` のアドレスを使ってください。

### 画面3：GitHub Pages を有効にする

1. リポジトリの **Settings** を開きます。
2. 設定メニューから **Pages** を選びます（左側、またはスマートフォン表示では上部の一覧にあります）。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. **Branch** の欄で次のように選びます。
   - 左のプルダウン：`main`
   - 右のプルダウン：`/ (root)`
5. **Save** を押します。

### 画面4：公開の完了を確認する

1. リポジトリの **Actions** タブを開きます。
2. 「pages build and deployment」という処理が表示されます。緑のチェックになるまで待ちます（通常は数分）。
3. **Settings → Pages** に戻ります。
4. 画面上部に「Your site is live at …」と公開URLが表示されていれば、公開は完了しています。
5. **Visit site** を押してサイトを開きます。

**公開URLは、この画面に表示されたものだけを正としてください。**

### 画面5：公開後の確認

公開したサイトを iPhone の Safari で開き、次の「2. 公開後の確認チェックリスト」を実施します。
