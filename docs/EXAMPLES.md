# 使用例とサンプルデータ

このページの値はすべて**架空**です。実在する企業・商品・顧客とは関係ありません。
アプリの初期状態（および「サンプルデータを読み込む」）と同じデータです。

## 例1：焼き菓子（8枚入り）を直販する場合

### 入力

| 項目 | 値 |
|---|---|
| 商品名 | サンプル焼き菓子 バターサブレ 8枚入 |
| 製造数量（1ロット） | 100 個 |
| 販売価格（税抜） | 1,200 円 |
| 販売先 | 直販 |

| 材料名 | 使用量（良品の正味量） | 単位 | 単価 | ロス率 |

| 薄力粉 | 4,000 | g | 0.4 円/g | 5% |
| 無塩バター | 2,000 | g | 2 円/g | 2% |
| グラニュー糖 | 1,500 | g | 0.3 円/g | 0% |
| 全卵 | 600 | g | 0.6 円/g | 10% |

**C. 包装資材費（1個あたり）**

| 資材名 | 数量 | 単価 |
|---|---|---|
| 化粧箱 | 1 | 45 円 |
| 個包装袋 | 8 | 3 円 |
| 商品ラベル | 1 | 8 円 |
| 封緘シール | 1 | 3 円 |

**D〜G**

| 区分 | 項目 | 値 |
|---|---|---|
| D. 人件費・製造経費 | 製造作業時間 | 6 時間 |
| | 1時間あたりの人件費 | 1,100 円 |
| | 人件費の区分 | 変動費 |
| | 変動製造経費 | 1,500 円 |

### 計算過程と期待値

**材料費（投入量 = 使用量 ÷ (1 − ロス率)）**

| 材料 | 計算 | 投入量 | 材料費 |
|---|---|---|---|
| 薄力粉 | 4,000 ÷ 0.95 | 4,210.53g | 1,684.21円 |
| 無塩バター | 2,000 ÷ 0.98 | 2,040.82g | 4,081.63円 |
| グラニュー糖 | 1,500 ÷ 1.00 | 1,500.00g | 450.00円 |
| 全卵 | 600 ÷ 0.90 | 666.67g | 400.00円 |
| **合計** | | | **6,615.84円/ロット**（66.16円/個） |

**1個あたり製造原価**

| 費目 | 区分 | ロット | 1個あたり |
|---|---|---|---|
| 材料費 | 変動費 | 6,616円 | 66.16円 |
| 包装資材費 | 変動費 | 8,000円 | 80.00円 |
| 製造人件費（6h × 1,100円） | 変動費 | 6,600円 | 66.00円 |
| 変動製造経費 | 変動費 | 1,500円 | 15.00円 |
| 固定製造経費（配賦） | 固定費 | 2,000円 | 20.00円 |
| **製造原価** | | **24,716円** | **247.16円** |

**利益**

| 指標 | 計算 | 値 |
|---|---|---|
| 粗利 | 1,200 − 247.16 | **952.84円**（粗利率 **79.4%**） |
| 変動製造原価 | 66.16 + 80 + 66 + 15 | 227.16円 |
| 販売関連変動費 | 手数料 120 + 送料 150 + その他 20 | 290.00円 |
| 限界利益 | 1,200 − 227.16 − 290 | **682.84円**（限界利益率 **56.9%**） |

**損益分岐点**

200,000 ÷ 682.84 = 292.89 → 切り上げて **293個**。損益分岐点売上高は **351,600円** です。

**価格比較**

| 項目 | 現在 1,200円 | 比較1 1,080円 | 比較2 1,300円 |
|---|---|---|---|
| 粗利 | 952.84円 | 832.84円 | 1,052.84円 |
| 粗利率 | 79.4% | 77.1% | 81.0% |
| 販売関連変動費 | 290.00円 | 278.00円 | 300.00円 |
| 限界利益 | 682.84円 | 574.84円 | 772.84円 |
| 限界利益の差（現在比） | — | −108.00円 | +90.00円 |
| 損益分岐点販売数量 | 293個 | 348個 | 259個 |

比較1では価格を 120円下げていますが、限界利益の減少は 108円です。手数料も 12円減るためです。

**表示される注意点**

| 段階 | 内容 |
|---|---|
| 注意 | ロス率が基準（10%）以上の材料：全卵 10% |
| 注意 | 包装資材費の割合が基準（30%）以上：32.4% |
| 確認 | 損益分岐点の前提、販売手数料の計算対象 |

## 例2：限界利益がマイナスになる条件の確認

例1で、販売価格だけを 300円 に変更します。

- 粗利：300 − 247.16 = 52.84円（粗利率 17.6%）
  - 粗利は黒字ですが、粗利率が基準（30%）を下回るため注意が出ます。
- 販売手数料：30円
- 限界利益：300 − 227.16 − 200 = **−127.16円**
- 損益分岐点：**計算不可**
- 計算結果の上部に赤い警告「限界利益が0以下です」が表示され、チェックリストに「要対応」が出ます。

粗利が黒字でも、販売関連費用を含めると1個売るごとに損失が出る例です。粗利と限界利益を区別して確認する必要があります。

## 例3：手数料の計算対象を税込にする

例1で「手数料の計算対象」を **税込販売価格**、消費税率を **8%** にします。

- 計算対象額：1,200 × 1.08 = 1,296円
- 手数料：129.60円
- 限界利益：1,200 − 227.16 − 129.60 − 150 − 20 = **673.24円**

この消費税率は手数料の計算にだけ使います。商品に適用される税率は利用者が確認してください。
