# 手動テスト手順

自動テスト（`tests/calc.test.js`、`tests/e2e.test.js`）でカバーしきれない、実機・実ブラウザ・Excel での確認に使う手順です。
結果は「確認日・環境・結果」を記録し、**実際に確認できた項目だけ**を「確認済み」としてください。

## 準備

- ローカル：`index.html` をダブルクリックして開く、または `npx serve .` などで配信する
- 公開版：GitHub Pages の URL を開く
- 期待値：[docs/EXAMPLES.md](../docs/EXAMPLES.md)

## チェック項目

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | ページを開く | 緑の「計算しました」が表示される。<br>1個あたり製造原価 247.16円／粗利 952.84円（79.4%）／限界利益 682.84円（56.9%）／損益分岐点 293個 |
| 2 | 「＋ 材料を追加」を押す | 材料5の行が追加される。<br>空欄のままなら結果は変わらない |
| 3 | 追加した行に 使用量 1000、単価 1、ロス率 20 を入力 | 行の下に「投入量 1,250.00g（ロス 250.00g）／ 材料費 1,250円/ロット」と表示される。<br>製造原価は 259.66円 |
| 4 | 追加した行の「削除」を押す | 製造原価が 247.16円 に戻る |
| 5 | 包装資材の「化粧箱」を削除 | 製造原価が 202.16円 になる |
| 6 | 製造数量を 200 に変更 | 「配賦の考え方」の数量が 200 になり、1個あたり製造原価が下がる |
| 7 | 比較価格を確認・変更 | 比較1（1,080円）の限界利益 574.84円、比較2（1,300円）は 772.84円。<br>値を変えると即時に再計算される |
| 8 | 販売価格を 300 にする | 赤い「限界利益が0以下です」が表示され、損益分岐点は「計算不可」になる |
| 9 | 商品名を空にする | 「入力内容を確認してください」が表示され、結果が「—」になる。<br>CSV ボタンが無効になる。<br>エラー一覧のリンクを押すと該当欄に移動する |
| 10 | 販売価格に `abc`、`-1`、`0`、`１，２００` を順に入力 | 最初の3つはエラー。最後の `１，２００` は 1,200 として計算される |
| 11 | 期間固定費を空にする | 損益分岐点が「計算不可（期間固定費が未入力）」になり、チェックリストに案内が出る |
| 12 | 手数料の計算対象を「税込販売価格」にする | 消費税率の欄が表示される。<br>8% で限界利益 673.24円 になる |
| 13 | 人件費の区分を「固定費」にする | 粗利は変わらず、限界利益が 66円 増える |
| 14 | 「H. 注意表示の基準」で粗利率を 90 にする | 「粗利率が設定基準（90%）を下回っています」が表示される |
| 15 | 商品名を `=1+1` にして CSV を出力し、Excel で開く | 文字化けしない。<br>商品名が `'=1+1` の文字列で表示され、計算されない。<br>数値が画面と一致する |
| 16 | 「すべてクリア」→「サンプルデータを読み込む」 | 確認ダイアログが出る。<br>クリア後はエラー表示になり、サンプル読込で例1の値に戻る |
| 17 | 開発者ツールのネットワークタブを開いて操作する | 自分のドメイン以外への通信が発生しない |
| 18 | 開発者ツールの Application タブを確認する | Local Storage・Session Storage・Cookie に何も保存されていない |
| 19 | 再読み込みする | 入力内容は残らず、サンプルデータに戻る |
| 20 | スマートフォン（幅 320〜414px）で開く | 横スクロールが出ない（価格比較の表の中だけは横スクロールできる）。<br>ボタンや入力欄が指で押しやすい。<br>入力時に画面がズームしない |
